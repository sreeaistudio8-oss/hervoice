HER VOICE — Music Website

HOW TO RUN
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Put your friend's 10 MP3 recordings in the songs folder.
4. Rename them exactly:
   song1.mp3, song2.mp3, ... song10.mp3
5. Open index.html using VS Code Live Server.

HOW TO CHANGE SONG NAMES
Open script.js. Find the tracks array near the top and edit the title values.
The audio file paths are already set to songs/song1.mp3 through songs/song10.mp3.

HOW TO CHANGE THE WEBSITE TITLE
Open index.html and replace HER VOICE / the page title with your preferred singer name.

The supplied photo is cropped to remove the black bars and used as the hero background.
